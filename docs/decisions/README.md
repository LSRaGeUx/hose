# Décisions

Un fichier par arbitrage structurant : le contexte, la décision, ce qu’elle
coûte. Les décisions sans conséquence négative n’en sont généralement pas.

Le format est volontairement court. Une décision qu’on ne peut pas expliquer en
une page est probablement plusieurs décisions.
